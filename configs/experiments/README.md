# Experiment configurations

Configurations are provided for the four cohorts and two feature encoders used in the study:

- `camelyon16_conch.yaml`
- `camelyon16_plip.yaml`
- `tcga_nsclc_conch.yaml`
- `tcga_nsclc_plip.yaml`
- `tcga_rcc_conch.yaml`
- `tcga_rcc_plip.yaml`
- `tcga_brca_conch.yaml`
- `tcga_brca_plip.yaml`

TCGA manifests use patient-level train/validation/test splits. The semantic prompts are stored in `../semantic_prompts.yaml`.
