# Figure utilities

The scripts in this directory generate the quantitative plots from CSV outputs produced by `evaluation/`, `audit/`, and `robustness/`.

- `plot_replacement_curves.py`: bag and fused feature-replacement curves
- `plot_key_sensitivity.py`: selected-patch budget sensitivity
- `plot_robustness.py`: AUC/F1 robustness curves
- `plot_mechanism_correlations.py`: mechanism correlation panels
- `plot_confusion_matrix.py`: confusion-matrix figure
